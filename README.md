# ClothesKids - Pantalla de inicio de sesión

Tarea 2 de Diseño de Interfaces: Del prototipo al código (I).

## Qué he hecho
- Preparé en Figma la pantalla de inicio de sesión: puse nombres a las capas, agrupé los elementos y anoté colores, tipografías y medidas en una ficha.
- Creé el proyecto en Android Studio (Java, API 28) y activé ViewBinding.
- Pasé los colores, textos, fuentes (Roboto), estilos y tema a recursos (`colors.xml`, `strings.xml`, `styles.xml`, `themes.xml`).
- Exporté el logo como SVG (VectorDrawable) y la foto de cabecera como PNG 3x convertida a WebP.
- Monté el layout de la pantalla con los mismos nombres que en Figma.
